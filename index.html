Train Sim Consist Builder

A high-performance, native Win32/C++ consist and activity editor for Open Rails (ORTS) and MSTS. Engineered with direct Kernel32 indexing, real-time physics metrics, and integrated 3D Visual Studio.

Engineered for Performance & Speed

⚡

Native C++ Performance

Zero electron bloat, zero Java/runtime overhead. Built purely in native Win32 C++ for instant startup and lightning-fast file parsing.

🎮

Integrated 3D Visual Studio

Real-time hardware-accelerated DirectX shape rendering with authentic material classification, specular highlights, and smooth alpha blending.

📊

Live Physics & Metrics

Live automated calculations for train length, combined mass in tonnes, horsepower (HP/kW), and unit composition breakdown.

🎲

Consist Pool Generator

Rule-based pool engine supporting sequential or randomized stock picking, orientation enforcement, and one-click bulk consist generation.

🔍

Health & Integrity Scanner

Automated detection of broken consist files, missing shape assets, invalid texture paths, and circular wagon linkages.

🔄

Reliable Built-in Updater

Automatic update verification powered directly by GitHub Pages CDN edge distribution with atomic in-place updates.
