### Task 2: Implement On-Demand File Streaming Engine

**Goal:** Enable instant directory reading without invoking Windows Explorer dialogs or scanning unnecessary subfolders.

* **Task 2.1: Implement High-Speed Kernel Traversal**
* In `TrainSimConsistBuilder.cpp`, write `ScanDirectoryStream()` using `FindFirstFileExW` with the `FIND_FIRST_EX_LARGE_FETCH` flag.
* Filter for relevant file extensions (`.eng` and `.wag` when building consists) and extract parent folder names.


* **Task 2.2: Setup Virtual List Views (`LVS_OWNERDATA`)**
* Instantiate a `SysListView32` in the Left Pane with `LVS_REPORT` and `LVS_OWNERDATA` styles.
* This ensures the UI never holds thousands of UI nodes—it only renders what fits on screen.


* **Task 2.3: Connect Address Bar to Streamer**
* Wire the Address Bar's `EN_CHANGE` or Enter key event to trigger `ScanDirectoryStream()`.
* When a path is entered, clear the local memory vector, stream the directory contents, and call `ListView_SetItemCount()` to update the UI instantly.


* **Task 2.4: Implement Flattened Column Rendering**
* Handle the `LVN_GETDISPINFO` notification in your window message loop (`WndProc`).
* Populate columns dynamically: **Filename**, **Parent Directory**, and **Type** (Locomotive / Wagon).

### Task 3: Link Left and Right Panes (Composition Engine)

**Goal:** Move selected assets from the Left Pane streamer into the Right Pane consist builder in memory.

* **Task 3.2: Implement Selection & Append Controls**
